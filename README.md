# 🕌 تطبيق المصليات الجامعية

تطبيق متكامل لإدارة المصليات الجامعية يوفر مواقيت الصلاة، الإعلانات، السبحة الرقمية، الأذكار، والمكتبة الإسلامية.

## 🎯 المميزات

- ✅ مواقيت الصلاة الدقيقة
- ✅ نظام إعلانات متعدد المستويات
- ✅ إدارة المصليات واللجان
- ✅ سبحة رقمية مع إحصائيات
- ✅ أذكار الصباح والمساء مع تذكيرات
- ✅ مكتبة إسلامية شاملة
- ✅ وضع ليلي/نهاري
- ✅ تخزين مؤقت ومزامنة

## 🛠️ التقنيات المستخدمة

### Frontend
- HTML5
- CSS3
- JavaScript (Vanilla)

### Backend
- Node.js
- Express.js
- MongoDB

## 📁 هيكل المشروع

```
mosque-app/
├── backend/           # Backend API
│   ├── config/       # إعدادات قاعدة البيانات
│   ├── models/       # نماذج البيانات
│   ├── routes/       # المسارات
│   ├── middleware/   # Middleware
│   ├── controllers/  # Controllers
│   ├── utils/        # أدوات مساعدة
│   └── server.js     # السيرفر الرئيسي
├── frontend/         # Frontend
│   ├── assets/       # الموارد (CSS, JS, صور)
│   ├── pages/        # الصفحات
│   └── index.html    # الصفحة الرئيسية
└── mobile/           # تطبيق الموبايل (Cordova)
```

## 🚀 البدء

### المتطلبات
- Node.js (v14 أو أحدث)
- MongoDB
- npm أو yarn

### التثبيت

#### 1. Backend

```bash
cd backend
npm install
```

#### 2. إعداد قاعدة البيانات

تأكد من تشغيل MongoDB، ثم أنشئ ملف `.env`:

```env
PORT=5000
MONGODB_URI=mongodb://localhost:27017/mosque-app
JWT_SECRET=your-secret-key-here
```

#### 3. تشغيل السيرفر

```bash
# للتطوير
npm run dev

# للإنتاج
npm start
```

السيرفر سيعمل على: http://localhost:5000

#### 4. Frontend

افتح ملف `frontend/index.html` في المتصفح، أو استخدم Live Server.

## 📱 أنواع المستخدمين

1. **المسؤول الأعلى**: إدارة كاملة للتطبيق
2. **مسؤول المصلى**: إدارة مصلى واحد وإنشاء لجان
3. **مسؤول اللجنة**: إدارة لجنة وإضافة أعضاء
4. **عضو اللجنة**: عضو في لجنة معينة
5. **مستخدم عام**: استخدام المميزات العامة

## 🔔 نظام الإشعارات

- إشعارات عامة من المسؤول الأعلى
- إشعارات المصلى من مسؤول المصلى
- إشعارات اللجنة من مسؤول اللجنة
